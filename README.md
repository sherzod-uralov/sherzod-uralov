### 👋 About me

I'm a full-stack engineer who works comfortably across three backend ecosystems — **Go**, **Rust**, and **Node.js** — and ships production frontends with **Vue/Nuxt**, **React/Next.js**, and **Angular**. I build multi-tenant SaaS platforms, CRMs, and real-time systems from database schema to deployed UI.

- 🔧 Backend: Go (Gin, Fiber), Rust (Axum, Rocket), Node.js (NestJS)
- 🎨 Frontend: Vue.js, Nuxt.js, React, Next.js, Angular
- 🗄️ Databases & infra: PostgreSQL, Docker, Git/CI-CD
- 🚀 Currently building large-scale metadata-driven SaaS products
