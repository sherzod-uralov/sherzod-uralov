## 👋 About me

I'm a full-stack engineer who works comfortably across three backend ecosystems — **Go**, **Rust**, and **Node.js** — and ships production frontends with **Vue/Nuxt**, **React/Next.js**, and **Angular**. I build multi-tenant SaaS platforms, CRMs/ERPs, and security systems end-to-end: schema → API → UI → deploy. I'd rather build the framework than just use one.

<table>
<tr><td valign="top">🧩</td><td><b>Own dependency-injection framework</b> for Node.js — NestJS-style DI/modules, TypeScript, with a CLI scaffolder.</td></tr>
<tr><td valign="top">🎨</td><td><b>Own React UI component library</b>, built from scratch with design tokens.</td></tr>
<tr><td valign="top">🛡️</td><td><b>Multi-tenant security control-plane</b> — FastAPI + PostgreSQL row-level security + Vue 3.</td></tr>
<tr><td valign="top">🦀</td><td><b>x86_64 operating system written from scratch in Rust</b> — custom Wayland compositor and shell.</td></tr>
</table>
