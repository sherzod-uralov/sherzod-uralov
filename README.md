## 👋 About me

I'm a full-stack engineer who works comfortably across three backend ecosystems — **Go**, **Rust**, and **Node.js** — and ships production frontends with **Vue/Nuxt**, **React/Next.js**, and **Angular**. I build multi-tenant SaaS platforms, CRMs/ERPs, and security systems end-to-end: schema → API → UI → deploy. I'd rather build the framework than just use one — several products below run on tooling I wrote myself.

```yaml
sherzod:
  backend:  [Go (Gin, Fiber), Rust (Axum, Rocket), Node.js (NestJS, Fastify), Python (FastAPI)]
  frontend: [Vue.js, Nuxt.js, React, Next.js, Angular]
  data:     [PostgreSQL, Prisma, Redis]
  infra:    [Docker, Git/CI-CD, Playwright]
  focus:    "metadata-driven, multi-tenant SaaS & security platforms"
```

**What I've built, not just used:**
- 🧩 My own NestJS-style dependency-injection/module framework for Node.js (TypeScript, CLI scaffolder included)
- 🎨 My own React UI component library with design tokens, from scratch
- 🛡️ A multi-tenant defensive security control-plane (FastAPI + PostgreSQL RLS + Vue 3)
- 🦀 An x86_64 operating system written from scratch in Rust (Wayland compositor + custom shell)
